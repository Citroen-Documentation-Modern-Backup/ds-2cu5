B1CG02P0Dépose - repose : Bielles/pistons
1. Démontage
Figure : b1cp00bc
Déposer les segments à l’aide d’une pince à segments.
Figure : b1cp00cc
NOTA : Un piston déposé à la presse n’est pas réutilisable.
Poser le piston sur le socle [ 20].
Chasser l’axe du piston avec le chasse [ 16].
2. Remontage
Figure : b1cp00dc
Placer l’axe du piston ( 1) sur le mandrin [18].
Visser le manche [ 17] sur le mandrin sans serrer.
L’axe ( 1) doit être libre en rotation.
Figure : b1cp00ec
Placer sur le socle [20] l’appui [19].
Poser le piston ( 2) sur l’appui [19] Positionner la flèche DT vers le haut.
Centrer l’ensemble avec le mandrin [ 18] et l’axe de piston.
Maintenir le piston avec la bride (3) du socle de positionnement [20].
Figure : b1cp00fc
Placer le pied de bielle sur une plaque chauffante électrique.
Figure : b1cp00gc
Poser sur le pied de bielle un morceau de soudure à l’étain ( 4).
Chauffer jusqu’à la fusion du morceau d’étain (température de 230°C environ).
Figure : b1cp00ic
IMPERATIF : Avant montage, huiler l’axe de piston ( 1).
ATTENTION : La réussite de cette opération, est conditionnée par la rapidité d’exécution . L’axe doit être emmanché d’un seul mouvement.
Essuyer la goutte d’étain.
Placer la bielle dans le piston, les arrêts de coussinets ( 5) orientés suivant la figure.
Engager rapidement l’axe ( 1) jusqu’en butée.
Attendre quelques secondes pour déposer l’ensemble bielle-piston.
Procéder de la même manière pour les trois autres ensembles.
3. Montage des segments
Figure : b1cp00jc
Poser les segments avec la pince à segments.
La face marquée TOP du segment d’étanchéité ( 7) doit être orientée vers le haut.
Orienter la coupe du segment ( 7) à 180° par rapport à la coupe du segment (6).
NOTA : Le segment racleur ( 8) de type UFLEX ne comporte pas de coupe.
Figure : b1cp00kc
Placer le collier à segments [ 27].
Laisser dépasser la partie basse "a" du piston pour assurer le guidage de celui-ci.
Aligner les flancs du collier [ 27] pour favoriser l’engagement du segment UFLEX.
Serrer modérément le collier [ 27] pour permettre le glissement de celui-ci lors de l’engagement du piston dans le cylindre.
