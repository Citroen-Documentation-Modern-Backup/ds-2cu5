D6AM0195P0Diagnostic : Contrôle du code confidentiel mémorisé dans le calculateur "Centrale Code"
1. Présentation
Contrôle du code confidentiel mémorisé dans le calculateur "Centrale Code".
2. Constatation
Il n’est pas toujours possible de déterminer si le code confidentiel mémorisé dans le calculateur "Centrale Code" est identique à celui inscrit sur la carte confidentielle client.
3. Introduction
Le code confidentiel est le code inscrit sur la carte confidentielle client (Electronic Code). Ce code confidentiel composé de 5 chiffres donne les possibilités suivantes :
  • Déverrouillage du calculateur "Centrale Code" pour effectuer un apprentissage des clés
  • Accès à certains menus de l’outil de diagnostic (Lecture clé ; Démarrage de secours ; A l’aide de l’outil de diagnostic)
  • Mise en œuvre des procédures de démarrage de secours
3 solutions permettent de contrôler si le code confidentiel est valide :
  • La procédure de démarrage de secours
  • La procédure de lecture des clés ; A l’aide de l’outil de diagnostic
  • La procédure de démarrage ; A l’aide de l’outil de diagnostic
4. Procédure de démarrage de secours (Contrôle du code confidentiel ; Sans outil de diagnostic)
La procédure de démarrage de secours permet de démarrer le moteur en manœuvrant la pédale d’accélérateur.
ATTENTION : À chaque mise du contact, l’antidémarrage est actif. Il est nécessaire de renouveler la procédure de démarrage de secours pour démarrer le moteur.
NOTA : La procédure de démarrage de secours n’est active qu’en cas de panne du Calculateur "Centrale Code" ou d’une clé non reconnue (Le témoin transpondeur reste allumé après la mise du contact).
ATTENTION : Un espacement de 10 minutes minimum est nécessaire entre plusieurs démarrages moteur. Dans le cas contraire, le démarrage moteur est interdit (Attendre 10 minutes contact mis).
4.1. Procédure de démarrage de secours
Opérations à effectuer :
  • Lire le premier chiffre du code inscrit sur la carte confidentielle client (Electronic Code)
  • Mettre le contact (+APC)
  • Le voyant de diagnostic moteur s’allume
  • Appuyer à fond sur la pédale d’accélérateur et maintenir l’appui jusqu’à l’extinction du voyant de diagnostic moteur
  • Relâcher la pédale d’accélérateur
  • Le voyant de diagnostic moteur commence à clignoter (Clignotement lent)
  • Après un nombre de clignotement égal au chiffre du code, appuyer à fond sur la pédale d’accélérateur et maintenir l’appui
  • Le voyant de diagnostic moteur s’allume à nouveau pendant 4 secondes puis s’éteint (Chiffre du code acquis)
  • Relâcher la pédale d’accélérateur
Répéter les opérations pour les autres chiffres du code confidentiel.
4.2. Reconnaissance du code confidentiel
Possibilité 1 : Le code confidentiel est reconnu par le calculateur "Centrale Code" :
  • Le voyant de diagnostic moteur clignote rapidement pendant 4 secondes puis reste allumé
  • Le démarrage du moteur est autorisé
Possibilité 2 : Le code confidentiel n’est pas reconnu par le calculateur "Centrale Code" :
  • Le voyant de diagnostic moteur reste allumé
  • Le démarrage du moteur est interdit
  • Couper le contact. La procédure peut être renouvelée
5. Contrôle du code confidentiel ; À l’aide d’un outil de diagnostic
NOTA : Les procédures décrites ne sont actives qu’en cas de panne du Calculateur "Centrale Code" ou d’une clé non reconnue (Le témoin transpondeur reste allumé après la mise du contact).
5.1. Solution 1 - Contrôle du code confidentiel par le calculateur "Centrale Code"
NOTA : Ces opérations nécessitent d’entrer en communication avec le calculateur "Centrale Code".
Outil de diagnostic LEXIA.
Étape Opérations à effectuer
1 Connecter l’outil de diagnostic sur le véhicule
2 Sélectionner "DIAGNOSTIC"
3 Renseigner le type de véhicule puis son numéro de châssis
4 Sélectionner l’item "antivol" ; Puis valider par la touche "*"
5 Sélectionner l’item "Centrale code" ; Puis valider par la touche "*"
6 Sélectionner l’item "Télécodage"
7 Sélectionner l’item "lecture clé"
8 Saisir le code confidentiel (Electronic Code inscrit sur la carte confidentielle client)
9 L’outil de diagnostic contrôle que le code saisi correspond au code mémorisé dans le calculateur "Centrale Code"
10 2 possibilités
- L’outil de diagnostic affiche les paramètres de la clé : Le code saisi est identique à celui mémorisé dans le calculateur "Centrale Code"
- L’outil de diagnostic affiche "code incorrect" : Le code saisi est différent de celui mémorisé dans le calculateur "Centrale Code"
5.2. Solution 2 - Contrôle du code confidentiel par le calculateur contrôle moteur
NOTA : Ces opérations nécessitent d’entrer en communication avec le calculateur contrôle moteur.
Outil de diagnostic LEXIA.
Étape Opérations à effectuer
1 Connecter l’outil de diagnostic sur le véhicule
2 Sélectionner "DIAGNOSTIC"
3 Renseigner le type de véhicule puis son numéro de châssis
4 Sélectionner l’item "Test par fonction"
5 Sélectionner l’item "motopropulseur" ; Puis valider par la touche "*"
6 Sélectionner le système d’injection ; Puis valider par la touche "*"
7 Sélectionner l’item "test actionneur" ; Puis valider par la touche "*"
7 Sélectionner l’item "tests divers" ; Puis valider par la touche "*"
8 Sélectionner l’item "antidémarrage"
9 Saisir le code confidentiel ; Puis valider par la touche "*"
10 Effectuer une tentative de démarrage
11 2 possibilités
- Le moteur démarre : Le code saisi est identique à celui mémorisé dans le calculateur contrôle moteur
- Le moteur ne démarre pas : Le code saisi est différent de celui mémorisé dans le calculateur contrôle moteur
