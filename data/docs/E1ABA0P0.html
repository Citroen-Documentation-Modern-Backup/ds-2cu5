E1ABA0P0Présentation : Antidémarrage codé avec déverrouillage par télécommande
DEPUIS SERIE 17000001
NOTA : Option suivant version ou pays.
1. Clés avec télécommande à distance
Ce système permet de verrouiller/déverrouiller à distance les ouvrants du véhicule :
  • portes avant
  • Portes arrière
  • Porte latérale coulissante
Le signal émis par la clé est reçu par un récepteur radiofréquence, implanté derrière la planche de bord côté passager.
2. Synchronisation des clés avec télécommande
Synchroniser les télécommandes avec le récepteur radiofréquence dans les cas suivants :
  • Mémorisation d’une nouvelle clé avec télécommande dans la centrale code
  • Remplacement du récepteur radiofréquence
NOTA : Il est nécessaire de disposer du password (code à 5 caractères).
Sélectionner successivement les menus suivants :
  • "RÉCEPTEUR RADIOFRÉQUENCES"
  • "TÉLÉCODAGE"
  • "TÉLÉCODAGE"
NOTA : Le code électronique est disponible au travers du système informatique "CORVET", lié au N° VIN du véhicule . Si le code électronique ne figure pas dans le système informatique "CORVET", contacter l’assistance technique.
NOTA : Ne pas confondre le "password" utilisé pour la mémorisation des télécommandes et le code électronique inscrit sur la centrale code, utilisé pour la mémorisation des transpondeurs.
3. Mémorisation d’une nouvelle clé dans la centrale code
Il est nécessaire d’effectuer les opérations suivantes :
  • Mémorisation du transpondeur
  • Mémorisation de la télécommande de la nouvelle clé du véhicule
