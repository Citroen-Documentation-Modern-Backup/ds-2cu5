B3FJ0CP0Remise en état : Étrier de frein avant
1. Démontage
Figure : b3fp01vc
Déposer les flexibles (1).
NOTA : Les flexibles ne doivent avoir ni bosses ni crevasses . Il est préférable de les remplacer ensemble.
Figure : b3fp01wc
Déposer les pistons ( 3).
Pousser le piston avec de l’air comprimé . Agir progressivement pour éviter une éjection brusque.
Les pistons et les alésages de l’étrier ne doivent pas présenter de traces d’abrasion ou de rayures, dans le cas contraire remplacer l’étrier complet.
Figure : b3fp01xc
À chaque démontage, remplacer :
  • Les joints d’étanchéité
  • Les pare-poussières (4)
  • Les soufflets de protection (5)
Déposer les vis de purge ( 6).
S’assurer que les vis de purge ( 6) ne sont pas bouchées.
Laver les pièces métalliques avec une solution d’eau chaude et de détergent.
2. Remontage
Huiler les pièces avec du liquide de frein avant le remontage.
Figure : b3fp01yc
Placer :
  • Le joint d’étanchéité ( 2) dans l’étrier
  • Le pare-poussière (4) dans la gorge de l’étrier
Figure : b3fp01zc
Monter le piston ( 3). Veiller à ne pas détériorer le pare-poussière.
Poser :
  • Les vis de purge ( 6)
  • Les flexibles
Remplacer les soufflets ( 5) sur les coulisseaux.
