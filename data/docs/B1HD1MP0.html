3. Mode opératoire
Figure : c5fp0fsc
Raccorder le manchon [ 2] sur le manomètre [1] avec tube "a".
Positionner l’outil [ 1] dans le véhicule.
IMPERATIF : Respecter les conditions de contrôle suivantes : Moteur à température de fonctionnement. Véhicule en état de marche. Moteur pleine charge.
Démarrer le moteur.
Engager le rapport de première vitesse, et démarrer le véhicule.
Engager les rapports jusqu’au 3ème rapport.
Décélérer jusqu’à un régime de 2000 tr/mn.
Accélérer progressivement.
Contrôler la pression : 0,95 ± 0,05 bar.
Déposer les outils [ 1] et [2].
Réaccoupler le tube ( 2) sur le conduit (1).
Serrer le collier .
