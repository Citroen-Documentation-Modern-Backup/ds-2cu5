E1AB9ZP0Présentation : Antidémarrage codé
DEPUIS SERIE 17000001
1. Préambule
L’antidémarrage codé immobilise le véhicule en verrouillant le calculateur moteur :
  • Le pilotage de l’injection et de l’allumage est impossible (moteurs essence)
  • Le pilotage de l’injection et de l’avance à l’injection est impossible (moteurs diesel)
2. Carte code
Figure : d4cp00jc
" a" : Code électronique des clés.
" b" : Code mécanique des clés.
Il s’agit d’une carte sur laquelle sont inscrits deux codes :
  • Le code électronique
  • Le code mécanique des clés
NOTA : Le code électronique est composé de 5 caractères.
Le code électronique est utilisé pour :
  • Le démarrage d’urgence
  • L’enregistrement des clés avec l’outil de diagnostic
NOTA : Perte de la carte code . Il est possible de commander une nouvelle carte code au service Pièces de Rechange.
3. Programmation des clés du véhicule À l’aide d’un outil de diagnostic
La centrale code peut mémoriser 8 clés au maximum.
Effectuer une programmation des clés dans les cas suivants :
  • Mémorisation d’une nouvelle clé dans la centrale code
  • Remplacement de la centrale code
NOTA : Il est nécessaire de disposer du code électronique inscrit sur la carte code du véhicule . Le code électronique est composé de 5 caractères.
Sélectionner successivement les menus suivants :
  • "CENTRALE FIAT CODE"
  • "TÉLÉCODAGE"
  • "APPRENTISSAGE DES CLÉS"
IMPERATIF : L’apprentissage d’une nouvelle clé implique l’apprentissage de l’ensemble des clés . L’identifiant du transpondeur d’une clé perdue ou volée est désactivée de la mémoire de la centrale code lors du réapprentissage des clés restant en possession du client.
NOTA : Il n’y a pas de clé "MASTER" rouge.
4. Visualisation de l’état de l’antidémarrage codé
Le témoin de l’antidémarrage codé, placé sur le tableau de bord est géré par la centrale code.
En plaçant la clé sur la position +APC, le témoin code signale une des conditions suivantes
État de l’antidémarrage codé État du témoin de l’antidémarrage codé
Calculateur verrouillé Éteint
Reconnaissance de la clé et fonctionnement correct du système Allumage bref puis extinction (0,7 s)
Pas de reconnaissance de la clé Témoin clignotant
Pas de liaison avec le calculateur moteur
Centrale code et calculateur moteur non appairés
Système en cours d’autodiagnostic Témoin allumé
NOTA : Si le témoin reste allumé, cela signifie que le code à été refusé . Mettre la clé sur STOP et recommencer l’opération depuis le début.
