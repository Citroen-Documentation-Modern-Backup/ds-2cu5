B1JG014VP0Dépose - Repose : Ligne d’échappement
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Tube avant d’échappement
1.1. Dépose
Placer le véhicule sur un pont élévateur à 2 colonnes.
Déposer la protection sous moteur.
Figure : b1jg061d
Déposer :
  • Les vis (1)
  • Les vis (2)
  • Le tube avant d’échappement (3)
1.2. Repose
ATTENTION : Respecter les couples de serrage .
NOTA : Remplacer les pièces défectueuses (Si nécessaire).
Reposer :
  • Le tube avant d’échappement (3)
  • Les vis (2)
  • Les vis (1)
1.3. Contrôle
Démarrer le moteur.
Vérifier l’absence de fuite de gaz d’échappement.
Reposer la protection sous moteur.
2. Silencieux arrière d’échappement
2.1. Dépose
Placer le véhicule sur un pont élévateur à 2 colonnes.
Déposer la protection sous moteur.
Figure : b1jg062d
Soutenir : Le silencieux arrière d’échappement (4) ; À l’aide d’un outil de levage.
Déposer les vis (7).
Déposer les suspentes d’échappement (5), (6), (8).
Déposer le silencieux arrière d’échappement (4).
2.2. Repose
ATTENTION : Respecter les couples de serrage .
NOTA : Remplacer les pièces défectueuses (Si nécessaire).
Mettre en place : Le silencieux arrière d’échappement (4) ; À l’aide d’un outil de levage.
Reposer : Les suspentes d’échappement (5), (6), (8).
Reposer les vis (7).
2.3. Contrôle
Démarrer le moteur.
Vérifier l’absence de fuite de gaz d’échappement.
Reposer la protection sous moteur.
