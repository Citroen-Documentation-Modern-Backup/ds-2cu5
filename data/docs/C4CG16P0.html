C4CG16P0Dépose - repose : Porte latérale coulissante
DEPUIS SERIE 17000001
1. Dépose
Figure : c4cp075c
Ouvrir la porte latérale coulissante de 10 cm.
Placer une chandelle [ 1] sous la porte latérale coulissante.
Figure : c4cp076c
Déposer les 2 vis (1).
Dégager le chariot central ( 2) de la porte latérale coulissante.
Figure : c4cp077c
Déposer les 2 vis (3).
ATTENTION : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Soutenir la porte et la dégager de la chandelle en la tirant vers soi.
Déposer la porte par le bas.
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
3. Réglage
Figure : c4cp078c
1 - Réglage de la position longitudinale.
2 - Réglage de la position verticale.
3 - Réglage de l’alignement.
3.1. Réglage de la position longitudinale
Figure : c4cp079c
Figure : c4cp07ac
Desserrer :
  • Les vis (5)
  • Les écrous
Régler la position de la glissière latérale ( 4).
NOTA : Les flèches montrent les sens de déplacement.
Serrer :
  • Les vis (5)
  • Les écrous
3.2. Réglage de la position verticale
Figure : c4cp07bc
Figure : c4cp07cc
Desserrer :
  • Les vis (1)
  • Les vis (7)
Régler la position verticale de la porte.
NOTA : Les flèches montrent les sens de déplacement.
Serrer :
  • Chariot central : Les vis (1) à 2,75 m.daN
  • Étrier inférieur : Les vis (7) à 3 m.daN
3.3. Réglage de l’alignement
Figure : c4cp07dc
Figure : c4cp07ec
Desserrer :
  • La vis (8)
  • Les vis (3)
Régler l’alignement de la porte.
NOTA : Les flèches montrent les sens de déplacement.
Serrer :
  • Chariot supérieur : La vis (8) à 3,8 m.daN
  • Étrier inférieur : Les vis (3) à 2,4 m.daN
3.4. Réglage des éléments de fermeture
Figure : c4cp07fc
Figure : c4cp07gc

  • Les 4 vis (9)
  • Les 4 vis (11)
Régler la position des 2 doigts de centrage (10) et des 2 bagues de centrage (12).
NOTA : Les flèches montrent les sens de déplacement.
Serrer :
  • Les 4 vis (11)
  • Les 4 vis (9)
3.5. Réglage du dispositif d’arrêt de porte
Figure : c4cp07hc
Déposer l’amortisseur de fermeture de porte ( 17).
Desserrer les 2 vis (14).
Régler le dispositif d’arrêt de porte ( 13).
Serrer les 2 vis (14).
S’il est nécessaire de régler la charge de retenue de l’ergot ( 16), agir sur la vis (15).
NOTA : Pour diminuer la charge, tourner la vis dans le sens horaire; pour l’augmenter agir sur la vis dans le sens antihoraire.
Poser l’amortisseur de fermeture de porte ( 17).
