DEPUIS SERIE 17000001
1. Dépose
Figure : c4bp02bc
Déposer les 2 vis (1).
Déposer les feux arrière (voir opération correspondante).
Débrancher les connecteurs des câbles passant dans la gaine ( 2).
Figure : c4bp02cc
La porte mi-ouverte, tirer le tirant de porte ( 3).
Ouvrir la porte en tenant le tirant de porte ( 3).
Figure : c4bp02dc
ATTENTION : Deux personnes sont nécessaires pour effectuer l’opération suivante.
Déposer les vis (4).
Déposer la porte arrière.
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
3. Réglage
Figure : c4bp02ec
Desserrer les vis (4).
Régler la position des portes.
NOTA : Les flèches montrent les sens de déplacement.
IMPERATIF : Serrer les vis (4) à 2,4 m.daN .
