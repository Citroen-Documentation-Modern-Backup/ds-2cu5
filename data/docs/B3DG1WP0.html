2. Opération préliminaire
Lever et caler le véhicule, roues arrière pendantes.
Déposer :
  • La roue
  • Le bouchon de moyeu
2.1. Freins arrière à tambours
Figure : b3fp17dc
Déposer :
  • Les vis (1)
  • Le tambour de frein
NOTA : Difficulté de dépose du tambour : Voir opération correspondante.
2.2. Freins arrière à disques
Déposer :
  • L’étrier de frein  (voir opération correspondante)
  • Le disque de frein  (voir opération correspondante)
3. Dépose
3.1. Moyeu arrière
Figure : b3dp00tc
Défreiner l’écrou (2).
Déposer :
  • L’écrou (2)
  • Le moyeu (3)
3.2. Fusée arrière (freins à tambours à l’arrière)
Figure : b3fp17ec
Déposer :
  • Les vis (4) À l’aide de l’outil [1]
  • La fusée
3.3. Fusée arrière (freins à disques à l’arrière)
Déposer les garnitures de freins de stationnement (voir opération correspondante).
Figure : b3fp17fc
Déposer :
  • Les vis (5)
  • Le plateau (6)
Figure : b3bp189c
Déposer vis (10).
Écarter le support de canalisation de frein (9).
Déposer vis (8).
Écarter le capteur d’ABS (7).
Déposer :
  • Les vis (11)
  • Le support (12)
  • Les vis (13)
  • La fusée
4. Repose
4.1. Moyeu arrière
Reposer :
  • Le moyeu (3)
  • L’écrou (2)
NOTA : Utiliser un écrou neuf.
Serrer l’écrou (2) à 45 ± 3 m.daN.
Figure : b3fp17gc
Freiner l’écrou (2) À l’aide de l’outil [2].
Le méplat "a" de l’outil doit toujours être dirigé vers l’extérieur.
Figure : b3dp00yc
ATTENTION : La jupe de l’écrou doit être freinée dans le sens opposé au serrage.
4.2. Fusée arrière (freins à tambours à l’arrière)
Figure : b3fp17hc
Reposer :
  • La fusée
  • Les vis (4) Avec l’outil [1]
Serrer les vis (4) à 15 ± 1,5 m.daN .
4.3. Fusée arrière (freins à disques à l’arrière)
Reposer :
  • La fusée
  • Les vis (13) (enduire les vis de LOCTITE FRENETANCH)
Serrer les vis (13) à 15 ± 1,5 m.daN .
Reposer :
  • Le support (12)
  • Les vis (11) Serrer à 20 ± 1 m.daN
  • Le capteur ABS (7)
  • La vis (8) (enduire les vis de LOCTITE FRENETANCH)
Serrer la vis (8) à 0,8 ± 0,2 m.daN.
Reposer :
  • Le support de canalisation de frein (9)
  • La vis (10)
  • Le plateau (6)
  • Les vis (5) Serrer à 2,5 ± 0,2 m.daN
  • Les garnitures de frein de stationnement (voir opération correspondante)

  • Le tambour de frein
  • Les vis (1) Serrer à 1,5 ± 0,2 m.daN
Reposer (freins à disques à l’arrière) :
  • Le disque de frein  (voir opération correspondante)
  • L’étrier de frein  (voir opération correspondante)
