D4CM02P0Opérations après-vente : Antidémarrage codé (centrale FIAT code 2)
DEPUIS SERIE 17000001
1. Apprentissage des clés
L’identifiant de la clé doit être mémorisé dans la centrale code pour permettre le démarrage du véhicule.
La centrale code peut mémoriser 8 clés au maximum.
IMPERATIF : Pour mémoriser une nouvelle clé dans la centrale code , Il est indispensable de réapprendre toutes les clés.
L’identifiant du transpondeur d’une clé perdue ou volée est désactivée de la mémoire de la centrale code lors du réapprentissage des clés restant en possession du client.
2. Remplacement de la centrale code
Lors du remplacement de la centrale code, il faut effectuer les opérations suivantes.
1 Demander au client toutes les clés qui sont restées en sa possession
2 Commander la pièce (fournir le numéro de châssis du véhicule)
3 Le service pièces détachées est en mesure de réaliser une centrale code ayant un code secret et un code fixe identiques à la centrale précédente. La base de données est mise à jour
4 Monter la nouvelle centrale code livrée vierge
5 Exécuter l’enregistrement des clés à l’aide de l’outil de diagnostic en introduisant toutes les clés précédemment habilitées (*)
6 Effectuer le contrôle final du système code avec un outil de diagnostic
(*) Se reporter à la brochure diagnostic "antidémarrage codé".
NOTA : Le code électronique ne peut pas être lu dans la centrale code.
3. Remplacement du calculateur moteur
Le calculateur moteur vierge et la centrale code sont appairés à la mise au +APC.
La mise au +APC doit se faire avec une clé reconnue par la centrale code.
Le calculateur moteur et la centrale code sont appairés automatiquement.
Le contrôle d’appairage est réalisé à la demande de l’utilisateur avec l’outil de diagnostic.
4. Démarrage d’urgence
4.1. Généralités
La procédure de démarrage d’urgence permet de démarrer le moteur en cas de défaillance du système antidémarrage codé.
Cette opération peut être effectuée à l’aide de outil de diagnostic ou avec la carte code.
La procédure de démarrage d’urgence est utilisée pour conduire le véhicule jusqu’au réseau du service Après Vente.
Après chaque coupure du contact, la procédure de démarrage d’urgence doit-être répétée.
4.2. Procédure de démarrage d’urgence
Procédure de l’opération avec le code électronique de la carte code, par appuis sur la pédale d’accélérateur.
Il faut utiliser le témoin de contrôle moteur pour gérer la procédure.
Le code électronique est transmis à la centrale code en agissant sur la pédale de l’accélérateur.
1 Lire les 5 chiffres du code de démarrage d’urgence sur la carte code
2 Placer la clé de contact en position +APC
3 Appuyer et maintenir la pédale d’accélérateur à fond de course. Le témoin de panne de l’injection s’allume pendant 4 secondes, puis s’éteint brièvement (150 ms) et se rallume pendant 4 secondes
4 Relâcher la pédale de l’accélérateur quand le témoin s’éteint. Au moment du relâchement de la pédale le témoin commence à clignoter à 1.25 seconde
5 Compter le nombre de clignotement. Lorsque le nombre de clignotement correspond au premier nombre du code électronique de la carte code, appuyer et maintenir à fond la pédale de l’accélérateur. Le témoin de contrôle moteur s’allume de nouveau pendant 4 secondes, puis s’éteint pour dire que le premier chiffre est acquis
6 Relâcher la pédale de l’accélérateur quand le témoin s’éteint
7 Après un nombre de clignotement égale au deuxième chiffre du code électronique, appuyer sur la pédale d’accélérateur. Le témoin de contrôle moteur s’allume de nouveau pendant 4 secondes, puis s’éteint pour dire que le deuxième chiffre est acquis. Répéter les étapes 6 et 7 pour les autres chiffres inscrit sur la carte code
8 Au moment du relâchement de la pédale après que le dernier chiffre a été acquis, le témoin clignote avec une fréquence double à environ une demi seconde pour indiquer que tout le code à été accepté
9 Mettre le moteur en marche
NOTA : Si le témoin reste allumé, cela signifie que le code à été refusé . Mettre la clé sur STOP et recommencer l’opération depuis le début.
5. Procédure d’intervention
5.1. Perte des clés
1 Demander au client toutes les clés qui sont restées en sa possession
2 Effectuer l’apprentissage des clés restante dans la centrale code, avec un outil de diagnostic. Pour les version équipées d’une télécommande, effectuer également l’apprentissage des télécommandes
3 Commander la clé en fournissant le numéro de châssis du véhicule
4 Le service Pièces de Rechange fournit une clé ayant :
- La même forme
- Un transpondeur ayant un nouveau identifiant mais avec le code secret de la centrale code
- Le même code mécanique
- Un nouveau code de télécommande HF
5 Exécuter l’apprentissage des clés à l’aide de l’outil de diagnostic en introduisant les clés neuves et celles en votre possession. Pour les version munies de télécommandes HF, introduire le code récepteur "password"
6 Effectuer le contrôle final du système code et du système d’alarme (si présent) avec un outil de diagnostic
(*) Selon version
NOTA : Le remplacement du transpondeur dans la clé n’est pas possible . Le transpondeur est solidaire du boîtier des clés.
5.2. Perte de la carte code
1 Demander au client toutes les clés qui sont restées en sa possession
2 Contacter le Service des Pièces de Rechange et fournir le numéro de châssis du véhicule
3 Le service Pièces de Rechange fournit une nouvelle carte code identique
4 Remettre la carte code au client en l’informant qu’il s’agit d’une copie. L’ancienne carte code permet encore le démarrage d’urgence du véhicule
