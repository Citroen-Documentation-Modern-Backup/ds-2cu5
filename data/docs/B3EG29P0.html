2. Repose
Reposer :
  • La colonne de direction (12)
  • Les écrous (11) (sans les bloquer)
  • Les vis (10)

  • Les vis (10) : 1,5 ± 0,2 m.daN
  • Les écrous (11) : 1,5 ± 0,2 m.daN

  • La colonne de direction
  • La vis (5) Serrer à 2,5 ± 0,2 m.daN

  • Les connecteurs (8)
