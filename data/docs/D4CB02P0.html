D4CB02P0Présentation : Antidémarrage codé (centrale FIAT code 2)
DEPUIS SERIE 17000001
1. Préambule
L’antidémarrage codé immobilise le véhicule en verrouillant le calculateur moteur :
  • Le pilotage de l’injection et de l’allumage est impossible (moteurs essence)
  • Le pilotage de l’injection et de l’avance à l’injection est impossible (moteurs diesel)
  • Le code utilisé entre la centrale code et la clé change à chaque démarrage (code tournant)
  • La centrale code possède un autodiagnostic direct
  • L’enregistrement des codes des clés est géré dans une base de donnés Pièces de Rechange
Les clés sont fournies "prémémorisées" avec le véhicule neuf.
Les clés "prémémorisées" permettent de supprimer les procédures d’enregistrement des clés ou de programmation au moment de la livraison du véhicule.
NOTA : Il n’y a pas de clé "MASTER" rouge.
2. Présentation du système
2.1. Centrale code
La centrale code a pour fonction principale la reconnaissance de la clé introduite.
La centrale code gère l’enregistrement de l’ensemble des clés autorisées et du témoin code au tableau de bord.
La centrale contient le Code Secret utilisé dans le dialogue avec le transpondeur de la clé.
La centrale code possède le "Code Fixe", code non crypté utilisé dans le dialogue avec le calculateur moteur.
La centrale code peut mémoriser 8 clés au maximum.
La centrale code possède une ligne de diagnostic directe indépendante de celle de la centrale de contrôle moteur.
2.2. Connecteurs de la centrale code
Figure : d4cp00gd
Connecteur B (3 voies) :
  • Voie 1 - Alimentation (+) de la bobine transpondeur
  • Voie 2 - Non connecté (NC)
  • Voie 3 - Alimentation (-) de la bobine transpondeur
Connecteur A (8 voies) :
  • Voie 1 - Non connecté (NC)
  • Voie 2 - Signale pour lampe témoin
  • Voie 3 - Alimentation directe
  • Voie 4 - Masse
  • Voie 5 - Ligne diagnostic
  • Voie 6 - Ligne sérielle de liaison avec le calculateur moteur
  • Voie 7 - Prédisposition pour relais extérieur : Non connecté
  • Voie 8 - Alimentation +APC
2.3. Clé à transpondeur - Bobine transpondeur
Les clés sont fournis à la livraison du véhicule neuf déjà mémorisées par l’usine de production.
Tous les codes sont ensuite enregistrés dans une base de données Pièces Rechange.
Au moment de la préparation du véhicule neuf aucune procédure d’enregistrement des clés n’est à faire.
Figure : d4cp00hd
Repère Désignation
1 Clé à transpondeur
2 Bobine transpondeur
Le boîtier de la clé de démarrage du véhicule renferme un transpondeur.
Le transpondeur est un système électronique passif.
Le transpondeur possède :
  • Un identifiant différent pour chaque transpondeur
  • Un "code secret" identique pour chacun des transpondeur du même jeu de clés
La bobine transpondeur est située sur le contacteur antivol de direction ( NEIMAN).
2.4. Calculateur moteur
Le calculateur moteur du véhicule doit mémoriser le "Code Fixe" de la centrale code (appairage avec la centrale code).
Le calculateur moteur est maître dans les échanges d’informations avec la centrale code.
La centrale code ne fait que répondre aux demandes du calculateur moteur.
2.5. Carte code
Il s’agit d’une carte sur laquelle sont inscrits deux codes :
  • Le code électronique
  • Le code mécanique des clés
Le code électronique est utilisé pour :
  • Le démarrage d’urgence
  • L’enregistrement des clés avec l’outil de diagnostic
Figure : d4cp00jc
a - Code électronique des clés.
b - Code mécanique des clés.
Le code électronique de la carte est utilisé pour effectuer les opérations suivants :
  • Programmer les clés à l’aide de l’outil de diagnostic
  • Programmer une centrale code
  • Utiliser la procédure de démarrage d’urgence à l’aide de la pédale de l’accélérateur ou de l’outil de diagnostic
3. Définition des codes de protection
3.1. Code fixe
Le code fixe est utilisé dans le dialogue entre la centrale code et le calculateur moteur.
Le code Fixe est mémorisé dans la centrale code et le calculateur moteur.
3.2. Code électronique
Le code électronique est inscrit sur la carte pour la procédure de démarrage d’urgence et de déverrouillage de la centrale code à l’aide de l’outil de diagnostic.
3.3. Code secret
Le code secret est situé dans le transpondeur de la clé, il est identique à un même jeu de clé.
3.4. Identifiant
L’identifiant est situé dans le transpondeur, il est différent pour chaque transpondeur d’un même jeu de clés.
