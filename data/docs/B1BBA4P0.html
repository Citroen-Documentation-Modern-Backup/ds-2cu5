2. Caractéristiques
2.1. Largeur palier "/"
Largeur palier "A" : 31 (+ 0,10 ; 0) mm.
2.2. Jeu latéral de vilebrequin
Le jeu latéral de vilebrequin se règle par 2 demi-coussinets avec épaulement  (côté volant moteur).
Le jeu latéral doit être compris entre 0,049 et 0,211 mm.
2.3. Jeu de fonctionnement - Paliers de vilebrequin
Le jeu de fonctionnement des paliers du vilebrequin, compris entre 0,032 et 0,102 mm, est obtenu par la création de 3 classes de demi-coussinets lisses inférieurs.
NOTA : Dans ce cas, il convient, pour déterminer le jeu avec précision, d’utiliser la jauge plastique PLASTIGAGE.
